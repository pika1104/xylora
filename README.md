## セットアップ

### GitHub Pagesの設定方法
1. リポジトリの **Settings** に移動
2. 左側メニューの **Pages** をクリック
3. **Build and deployment** セクションで：
   - **Source** を「Deploy from a branch」に設定
   - **Branch** を「main」に設定
   - **Folder** を「/ (root)」に設定
4. **Save** をクリック

設定後、GitHub Pagesの公開URLにアクセスしてサイトを確認できます。
